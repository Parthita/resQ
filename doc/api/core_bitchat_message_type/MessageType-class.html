MessageType

MessageType class

Wire message types for the BitChat protocol (port of MessageType.swift).

These are the high-level "what is this packet" tags carried in the packet header's type byte. We only need a subset for our mesh, but we keep the full enum so we can decode native packets without dropping them.

Dart note: enum with an explicit UInt8 value is expressed as a class with a static const per type. This keeps the value mapping identical to the Swift source.
